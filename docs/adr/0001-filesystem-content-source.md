# ADR-0001：文件系统是内容事实来源

- Status: Accepted
- Date: 2026-08-05

## 背景

OpenWorkspace 面向希望直接维护 Markdown、HTML 和附件的个人内容作者。如果框架把正文复制到数据库或内部模型，用户需要处理导入、导出、同步和数据锁定问题。

## 决定

- 私有工作区中的真实文件是站点内容的唯一事实来源；当前路径由 ADR-0004 定为 `workspace/modules/`。
- 框架在构建期读取文件，但不把正文迁移或复制到数据库。
- Git 负责内容版本历史。
- 生成的 `<distRoot>/` 只是不具备反向所有权的发布产物。

## 后果

正面影响：

- 内容可由任意编辑器维护，能够直接备份、搜索和版本控制。
- 框架升级不需要迁移用户正文数据库。
- 内容和页面 URL 的来源可追溯。

代价：

- 内容变化需要重新构建静态站点。
- 搜索、权限和在线编辑需要额外架构，不能依赖数据库现成功能。
- 文件移动会改变基于路径的 URL。
