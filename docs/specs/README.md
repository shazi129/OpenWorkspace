# 功能 Spec

Spec 描述功能的期望行为、非目标和可验证的验收条件，不承担架构说明或逐次修改历史。

## 状态

- `Proposed`：讨论中。
- `Accepted`：需求已确认，实现未完成。
- `Implemented`：当前代码满足验收条件。
- `Superseded`：已被其他 spec 替代。

## 新 Spec 模板

```md
# 功能名称

- Status: Proposed
- Updated: YYYY-MM-DD

## 背景

## 目标

## 非目标

## 行为要求

## 验收条件

## 关联模块与 ADR
```
