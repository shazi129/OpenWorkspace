# 内容目录树

- Status: Implemented
- Updated: 2026-08-08

## 背景

文章模块需要从真实文件目录生成可导航的目录树，同时避免“目录名和唯一文章名重复”的冗余层级，并允许用户在不同屏幕宽度下调整目录空间。

## 目标

- 目录树反映可展示的 Markdown/HTML 内容。
- 当前文章路径易于识别和定位。
- 目录与内容文件通过不同图标快速区分。
- 单内容目录自动折叠，但真实 URL 保持稳定。
- 桌面目录宽度可调，整棵目录树可收起和恢复。
- 长文件名不换行破坏树形层级。

## 非目标

- 按 Frontmatter `order` 排序。
- 在目录树直接展示图片或附件。
- 通过目录折叠改变文件系统结构或页面 URL。
- 绕过当前 Astro 静态路由对字面量 `%` 文件名的限制。

## 行为要求

1. 只有 `.md`、`.html`、`.htm` 生成文件节点。
2. 空目录及只包含资源文件的目录不展示。
3. 目录只有一个内容文件时直接返回该文件节点；资源文件不计入内容数量。
4. 单文件折叠递归生效，文件的 `slug` 和 `href` 保留完整真实路径。
5. 包含多个内容节点的目录保留为目录节点。
6. 目录使用可展开三角，当前文件祖先目录默认展开。
7. 从目录树站内跳转时保留用户已展开的兄弟目录；直接访问、刷新或外部链接进入时，只按当前文件路径默认展开。
8. 模块根目录的 `index.md` 不进入目录树；配置为首页的 `content/` 文件仍显示并作为默认定位节点。
9. 目录节点显示文件夹图标，Markdown/HTML 内容节点显示文档图标；装饰图标不应产生额外的屏幕阅读器文本。
10. 文件名保持单行，超长时省略并可查看完整名称。
11. 桌面端可以通过分隔条指针拖动或键盘调整宽度。
12. 用户可以收起和展开整棵目录树；宽度和收起状态在浏览器本地保存。
13. 移动端不提供宽度拖动，但保留目录展开/收起能力。
14. 文件或目录名称可以包含 `#`，构建时必须读取真实文件并把页面 URL 编码为 `%23`。

## 验收条件

- 单 Markdown 文件加多个图片的目录只显示文章，不显示外层目录。
- 多内容目录仍显示目录及全部内容节点。
- 多层目录最终只有一个内容文件时可以递归折叠。
- 折叠前后的文章 URL 完全一致。
- 当前页面链接带 `aria-current="page"`。
- 目录树内跳转后保留已展开兄弟目录，直接 URL 访问时不恢复旧展开状态。
- 根 `index.md` 不显示；配置的 `content/` 首页文件显示并高亮。
- 目录和内容文件分别显示文件夹、文档图标，图标不改变节点原有的可访问名称。
- 分隔条具有 separator 语义、键盘控制和宽度边界。
- `tests/unit/content-loader.test.ts` 覆盖单文件、多文件和递归折叠。
- 包含 `#` 的 Markdown 文件可以完成内容加载和静态构建，生成的 URL 使用 `%23`。
- `npm run check`、`npm test`、`npm run build` 通过。
