# 设置与重新生成

- Status: Implemented
- Updated: 2026-08-07

## 目标

- 模块工具栏底部提供齿轮设置入口。
- 当前设置面板提供“重新生成”。
- 重新生成按顺序执行 `git pull --ff-only` 和 `npm run build`。
- 操作需要管理令牌，且同一时间只能执行一个任务。

## 行为要求

1. 设置入口固定在模块工具栏底部，桌面和移动端均可操作。
2. 点击重新生成时在当前浏览器会话中获取管理令牌，并以 Bearer 令牌发送 POST 请求。
3. 拉取失败时不执行构建；构建失败时保留后台日志并向前端返回失败状态。
4. 已有任务执行时返回冲突状态，不能启动并行的 Git/构建任务。
5. 成功后刷新当前页面以展示新构建内容。
6. 服务默认只监听回环地址，Nginx负责外部 TLS、访问控制和反向代理。

## 非目标

- 在浏览器中展示完整 Git 或构建日志。
- 自动解决 Git 冲突、覆盖本地修改或执行强制重置。
- 把令牌、服务代码、数据库写入 `dist/`。

## 验收条件

- 未提供或提供错误令牌时返回 401。
- `git pull --ff-only` 成功后才执行 `npm run build`。
- 拉取失败的测试确认构建不会执行。
- API 健康检查和服务发现测试通过。
- `npm run check`、`npm test`、`npm run build` 通过。

实现结构见[私有服务运行时](../architecture/modules/service-runtime.md)。
